# Bloque ton facho pour Chrome

Fonctionne aussi sur les navigateurs basés sur Chromium : Edge, Brave, Opera, Vivaldi, Arc.

## Installation

1. Télécharge [`bloque-ton-facho.zip`](bloque-ton-facho.zip) (bouton **Download raw file** sur la page GitHub).
2. Décompresse le zip : tu obtiens un dossier `bloque-ton-facho`.
3. Ouvre `chrome://extensions` (`edge://extensions`, `brave://extensions`…).
4. Active le **Mode développeur** (en haut à droite).
5. Clique **Charger l'extension non empaquetée** et choisis le dossier `bloque-ton-facho`.
6. Recharge l'onglet Threads.

> Garde le dossier décompressé quelque part : si tu le supprimes, Chrome désactive l'extension.

Astuce : épingle l'extension (icône puzzle 🧩 → punaise) pour accéder vite au popup de réglages.

## Mise à jour

1. Télécharge le nouveau zip et remplace l'ancien dossier par le nouveau (même emplacement).
2. Dans `chrome://extensions`, clique ↻ sur la carte de l'extension.
3. Recharge Threads.

Tes réglages (mots-clés, phrases, historique) sont conservés.

## Désinstallation

`chrome://extensions` → **Supprimer** sur la carte de l'extension, puis supprime le dossier.

## Si rien n'apparaît sur Threads

- Vérifie que l'extension est activée dans `chrome://extensions`.
- Recharge l'onglet Threads (les boutons n'apparaissent pas sur un onglet ouvert avant l'installation).
- Si Chrome affiche « Erreurs » sur la carte de l'extension, clique dessus et ouvre une issue avec le message.

Voir le [README principal](../README.md) pour l'utilisation.
